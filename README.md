# Linux Server Monitoring & Backup Automation

A practical Linux administration project using Bash scripting and Cron.

## Features

- System monitoring
- CPU, RAM and disk monitoring
- Linux service monitoring
- Automated server backup
- Bash scripting
- Cron automation

## Scripts

- system_monitor.sh - Monitors system health
- service_monitor.sh - Checks important Linux services
- backup.sh - Creates compressed server backups

## Technologies

- Linux
- Bash
- Cron
- Git
- GitHub
